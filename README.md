# Agent-Free-Windows

دستیار هوشمند دسکتاپ ویندوز با رابط فارسی، ارائه‌دهندگان مدل ابری سازگار با OpenAI API و ابزارهای محلی با تأیید کاربر.

## وضعیت
این مخزن شامل سورس نسخه اولیه پروژه است. پیش از استفاده عملی، آن را بررسی و آزمایش کنید.

## اجرا
نیازمند Python 3.11+ است:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

برای اتصال، API key معتبر ارائه‌دهنده‌تان را در تنظیمات وارد کنید. سهمیه یا دسترسی رایگان تضمین نمی‌شود.
